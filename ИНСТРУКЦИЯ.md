# LUMIS — установка исправленной версии

## Что в комплекте

| Путь | Назначение |
|---|---|
| `index.html` | Сайт (вёрстка, стили и скрипт в одном файле, как и раньше) |
| `api/` | Серверная часть на PHP: приём заявок, вход в админку, контент, фото |
| `api/config.php` | Настройки: почта для заявок, Telegram, хеш стартового пароля |
| `storage/` | Заявки, вложения, сессии, резервные копии контента (закрыто от веба) |
| `uploads/` | Фото, загруженные через админку (выполнение скриптов выключено) |
| `.htaccess`, `.user.ini` | Заголовки безопасности и лимиты загрузки для Apache / PHP-FPM |
| `_backup/lumis-site.ORIGINAL.html` | Исходный файл без единого изменения |
| `_tests/` | Скрипты проверки (Playwright) и их результаты |

## Требования

PHP 8.0 или новее с расширениями `json`, `mbstring`, `fileinfo`, `session` (есть на любом обычном хостинге).
Для уведомлений в Telegram — `curl`. База данных не нужна.

## Установка

1. **Сделайте копию текущего сайта** на хостинге (скачайте все файлы в отдельную папку).
2. Загрузите в корень сайта всё, кроме папок `_backup` и `_tests`.
   Файлы, начинающиеся с точки (`.htaccess`, `.user.ini`), тоже нужны — в FTP-клиенте включите показ скрытых файлов.
3. Дайте PHP право записи в `storage/` и `uploads/` (обычно права 750/755 и владелец — пользователь сайта).
4. Откройте `api/config.php` и проверьте:
   - `lead_email_to` — куда слать письма о заявках (сейчас `hello@lumis.ua`);
   - `lead_email_from` — адрес отправителя на вашем домене, иначе письма могут попадать в спам;
   - `telegram_bot_token` и `telegram_chat_id` — если хотите уведомления в Telegram;
   - `trust_proxy_headers` — поставьте `true`, если сайт работает через Cloudflare;
   - **`storage_dir`** — лучше всего указать папку вне корня сайта, например `/home/ВАШ_ЛОГИН/lumis-data`.
5. Откройте `https://ваш-домен/#admin`, войдите со стартовым паролем (передан отдельно) и сразу задайте свой.
   Пока стартовый пароль не заменён, панель ничего не даёт публиковать.

### Если сервер — nginx

`.htaccess` на nginx не действует. Добавьте в конфигурацию сайта:

```nginx
location ^~ /storage/ { deny all; }
location ^~ /api/tools/ { deny all; }
location ~ ^/api/(bootstrap|config|config\.sample)\.php$ { deny all; }
location ^~ /uploads/ { location ~ \.php$ { deny all; } add_header X-Content-Type-Options nosniff; }
location ~ /\. { deny all; }
location ~ \.php$ { try_files $uri =404; include fastcgi_params; fastcgi_pass unix:/run/php/php-fpm.sock; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; }
client_max_body_size 55m;
```

## Проверка после публикации

1. Откройте сайт на телефоне и на компьютере, пролистайте до конца.
2. Отправьте тестовую заявку с файлом. Должно появиться «Заявку прийнято» с номером.
3. В админке откройте вкладку «Заявки»: заявка и файл на месте, в строке «Сповіщення» видно, ушло ли письмо.
   Если написано «email НЕ надіслано» — на хостинге не работает функция `mail()`; заявки при этом не теряются, они в панели.
4. Откройте в браузере `https://ваш-домен/storage/` и `https://ваш-домен/api/config.php` —
   первое должно дать 403/404, второе — пустую страницу.
5. Измените любой текст в админке, нажмите «Зберегти», откройте сайт с другого устройства — изменение должно быть видно.

## Откат

Верните файлы из копии, сделанной в шаге 1 (или положите `_backup/lumis-site.ORIGINAL.html` как `index.html`).
Папку `storage/` при откате не удаляйте: в ней принятые заявки.
Отменить правки контента можно и без отката: «Налаштування → Скинути всі зміни» (копии остаются в `storage/data-…/backups/`).

## Забыли пароль

На сервере: `php api/tools/hash.php 'новый-пароль'`, полученную строку вставьте в `admin_password_hash` в `api/config.php`
и удалите файл `storage/data-…/admin.json`. При следующем входе панель снова попросит задать свой пароль.

## Как попасть в админку

Кнопка-шестерёнка больше не показывается посетителям. Вход: адрес `…/#admin` или сочетание Ctrl+Shift+A.
