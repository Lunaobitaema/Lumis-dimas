# LUMIS — сайт рекламной продукции

Исправленная и проверенная версия сайта: одна страница `index.html` и небольшая серверная часть на PHP
(приём заявок с файлами, админ-панель, хранение контента).

- Установка, проверка после публикации и откат — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
- Исходный файл без изменений — `_backup/lumis-site.ORIGINAL.html`.
- Автотесты (Playwright) и их результаты — `_tests/`.

## Настройки не лежат в репозитории

Репозиторий публичный, поэтому `api/config.php` в него не входит. Перед запуском:

1. Скопируйте `api/config.sample.php` в `api/config.php`.
2. Создайте хеш стартового пароля: `php api/tools/hash.php 'ваш-пароль'` (от 10 символов)
   и вставьте его в `admin_password_hash`.
3. Заполните `lead_email_to` — адрес, на который приходят заявки.

Токен Telegram-бота и другие секреты вписывайте только в `api/config.php` на сервере; этот файл в `.gitignore`.

## Требования

PHP 8.0+ (расширения `json`, `mbstring`, `fileinfo`, `session`), база данных не нужна.
GitHub Pages для этого сайта не подходит: там не выполняется PHP, заявки приниматься не будут.
